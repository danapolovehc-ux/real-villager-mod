# Real Villager 1.0.0

This is the original Real Villager build, restored without the experimental Academy or player-tutorial code.

The mod provides RealTime-based citizen schedules and city behavior. Its original dependencies, events, and localization files are included alongside the DLL.

## Installation

Copy this folder into `%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods` and enable **Real Villager** in Content Manager > Mods.

## Rollback

The original DLL is preserved as `RealVillager.dll.backup-before-academy-merge`.
